# Zach Coble

**Practical IT systems. Clear documentation. Steady improvement.**

I build and document hands-on projects in Linux, Windows administration, networking, and automation. My focus is making systems easier to operate, troubleshoot, and rebuild.

## What I'm working on

- **Homelab operations:** virtualization, self-hosted services, private remote access, monitoring, and recovery documentation.
- **IT utilities:** PowerShell and Bash tools for system inventory and repeatable support tasks.
- **Linux practice:** RHEL administration, service management, security fundamentals, and networking labs.
- **Small applications:** Python tools that turn everyday workflows into useful software.

## How I work

I prefer simple solutions, scoped access, readable version history, and documentation that lets someone else pick up the work. I use AI tools to help build and investigate, and verify the result with tests and practical checks.
